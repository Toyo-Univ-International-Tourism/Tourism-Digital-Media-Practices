# utils/practice1/ — 観光地サンプル画像

練習① で学生が選んで使う観光地の写真を配置するフォルダ。

## 仕様
- ファイル名: 半角英数 (例: `itsukushima.jpg`, `mtfuji.jpg`)
- 解像度: 横 1920px 程度
- ファイルサイズ: 200-400 KB 目標 (mozjpeg q=80-85)
- ライセンス: 商用利用可・クレジット不要のロイヤリティフリー素材 (Unsplash / Pixabay / Wikimedia Commons CC0 等)
