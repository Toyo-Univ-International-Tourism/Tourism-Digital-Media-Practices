# 360°パノラマ素材（Poly Haven）

演習で使う 360°（全天球）背景画像です。すべて **Poly Haven** から入手したフリー素材です。

## 入手元

- サイト: Poly Haven — HDRIs <https://polyhaven.com/hdris>
- 各シーンの個別ページは下の一覧を参照

- 参考: Poly Haven ライセンス <https://polyhaven.com/license>

## 形式について

- オリジナルは 4K の HDR ファイル（`.hdr`, equirectangular, 4096×2048, 各約25MB）。
- Web / 演習で扱いやすいよう、**JPG（4096×2048）に変換して軽量化**しています（各 約0.4〜1.6MB）。
- 変換コマンド（参考）: `ffmpeg -i <name>_4k.hdr -q:v 3 <name>_4k.jpg`
- HDR オリジナルが必要な場合は上記 Poly Haven の各ページから再ダウンロードできます。
